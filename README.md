# Almoxarifado
Sistema de almoxarifado para o SENAI feito pela turma Tercetroia

##Objetivos do projeto:
Este sistema foi desenvolvido na disiplina de Implantação de Sistema do SENAI. O objetivo é controlar o estoque de materias de TI e escritório da instituição. Registrando entradas, saídas e gerando alertas de estoque baixo.
